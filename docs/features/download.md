# 下载歌曲

在歌曲的右键或更多菜单中选择“下载”。歌单和专辑的更多菜单提供“下载全部”。默认保存到用户目录下的 `Music/Mygo Music`，首次下载时自动创建。可以在“设置 → 下载”中修改目录和默认音质，已选择的目录会继续使用。

下载音质与播放音质分别保存。网易云可能提供较低的音质，也可能因为账号权限没有提供下载地址；任务中会显示实际返回的音质或失败原因。音乐网盘使用已有的网盘歌曲地址。

文件会内嵌歌名、歌手、专辑、专辑歌手、发行日期、曲序、碟号和厂牌等来源提供的字段，以及专辑封面、带时间戳的歌词和译文。曲序和总数来自专辑，不取歌单顺序。没有提供的字段不编造；缺少封面或歌词时会在完成的任务中说明。网盘文件优先保留自己原有的标签、封面和歌词，只补缺失内容。

需要独立歌词文件时，打开“另存歌词文件”，会在音频旁边保存同名 `.lrc`。文件名格式可选“歌手 - 歌名”“歌名 - 歌手”或“仅歌名”，对新加入队列的任务生效；缺少歌手时直接使用歌名，已有的音频扩展名会去掉后再按实际格式添加一次。文件重名时会增加编号，不覆盖已有文件。

下载时复用完整且符合实际音质、格式和大小的缓存，或使用播放器已有的下载器获取原始音频，再在独立副本上写标签。不会转码，也不会改播放缓存。写入并读回验证成功后，文件才会出现在最终路径。失败可以重试；取消和退出会停止尚未完成的任务。下载列表本次启动内保留，不会在重启后自动续传。

## 格式与验证

统一使用固定版本 `go.senan.xyz/taglib v0.15.0`，通过已有的 Wazero 运行 TagLib，不需要系统安装额外程序。许可证随安装包放在 `licenses` 目录。

MP3、FLAC、WAV（整数和浮点）、Ogg Vorbis、ADTS AAC／HE-AAC、M4A AAC／ALAC／HE-AAC，以及归一化为 M4A 的 3GP／3G2，均有标签、封面和歌词读回测试。测试还用播放器本身对比写入前后全部 PCM 样本；分片 M4A 也在覆盖范围内。

这些验证覆盖本地格式和模拟服务的下载流程。具体账号对歌曲的下载权限、网易云实际返回的音质，需要在已登录的测试版中确认。不同外部播放器对内嵌时间戳歌词和 WAV／AAC 标签的展示方式可能不同，同名 LRC 可以用于不读取这些标签的播放器。

macOS 的签名包还需要实际执行验证。TagLib 和 HE-AAC 解码器使用的 Wazero 会在运行时生成机器码；当前版本通过匿名内存与 `mprotect` 执行这些代码，因此签名配置包含 `allow-unsigned-executable-memory` 权限。普通 `go test` 和静态验签无法代替这项检查；`local.download.1` 曾因此在开始写标签时被系统终止。

在 macOS 上运行 `python3 scripts/test_signed_download.py`，会以 Hardened Runtime 签名测试程序，再在独立进程中执行下载、标签写入、读回和解码测试，分别覆盖冷、热缓存。默认使用临时签名；发布前可通过 `--identity` 指定应用实际使用的证书，通过 `--output` 保留日志。最终安装包还要核对实际签入的权限。
